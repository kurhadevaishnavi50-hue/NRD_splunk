# Splunk Queries – Network Reconnaissance Detection

This document contains the Splunk SPL queries used for analyzing reconnaissance alerts generated by the Python detection scripts.

## 1. Verify Ingested Data

```spl
index=network_recon
```

Used to verify that reconnaissance events are successfully ingested into Splunk.

---

## 2. Check Total Events

```spl
index=network_recon
| stats count
```

Displays the total number of reconnaissance events indexed.

---

## 3. Check Scan Types

```spl
index=network_recon
| stats count by scan_type
```

Shows the number of detected events for each reconnaissance scan type.

Example scan types:

* SYN Scan
* UDP Scan
* FIN Scan
* NULL Scan
* XMAS Scan

---

## 4. Check Severity Distribution

```spl
index=network_recon
| stats count by severity
```

Displays the distribution of detected events according to severity.

---

## 5. Identify Top Source IPs

```spl
index=network_recon
| top source_ip
```

Identifies the source IP addresses generating the most reconnaissance activity.

---

## 6. Reconnaissance Activity Timeline

```spl
index=network_recon
| timechart count by scan_type
```

Displays reconnaissance activity over time and separates events by scan type.

---

## 7. View Recent Alerts

```spl
index=network_recon
| table timestamp source_ip scan_type count severity
```

Displays important alert fields in a table for investigation.

---

## 8. High-Severity Events

```spl
index=network_recon severity=HIGH
```

Filters the events to show only high-severity reconnaissance activity.

---

## 9. Critical Events

```spl
index=network_recon severity=CRITICAL
```

Filters the events to show critical reconnaissance activity.

---

## 10. Count High-Severity Events

```spl
index=network_recon severity=HIGH
| stats count
```

Counts the number of high-severity reconnaissance events.

---

## 11. Analyze Events by Source IP and Scan Type

```spl
index=network_recon
| stats count by source_ip scan_type
```

Shows which source IP performed which type of reconnaissance activity.

---

## 12. Analyze Severity by Scan Type

```spl
index=network_recon
| stats count by scan_type severity
```

Shows the severity distribution for each scan type.

---

## 13. Verify Extracted Fields

```spl
index=network_recon
| fieldsummary
```

Used to verify that Splunk correctly extracted fields such as:

* `timestamp`
* `source_ip`
* `scan_type`
* `count`
* `severity`

---

## 14. Recent High-Severity Alerts

```spl
index=network_recon severity=HIGH
| table timestamp source_ip scan_type count severity
| sort - timestamp
```

Displays recent high-severity reconnaissance events.

---

## 15. Source IP Activity

```spl
index=network_recon
| stats count by source_ip
| sort - count
```

Ranks source IP addresses according to the number of detected events.

---

# Splunk Alert Query

For detecting high-severity reconnaissance activity:

```spl
index=network_recon severity=HIGH
```

Alert condition:

```text
Number of Results > 0
```

This can be configured to trigger a notification when a high-severity reconnaissance event is detected.

## Notes

* `network_recon` is the Splunk index used for reconnaissance alerts.
* Field names assume the CSV uses machine-friendly names such as `source_ip`, `scan_type`, and `severity`.
* Set the Splunk time range to **All Time** when testing historical data.
* These queries are intended for the project data generated by the accompanying Python detection scripts.
